About GeoSwipe Viewer

Open-source GitHub Pages static web app

This application utilizes MapLibre GL JS and the mapbox-gl-compare curtain swipe controller to deliver high-performance raster layer comparisons right inside your browser with zero server-side dependencies.

You can easily host this entire single-file HTML application directly on GitHub Pages by pushing it to a repository and enabling GitHub Pages in your settings.

To swap out imagery sources for your own custom GeoTIFFs or tile servers, simply edit the tile URL strings in the JavaScript configuration block.
